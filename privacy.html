Polityka prywatności

Informacja o danych używanych przez prywatny dashboard domowy.

Wersja dokumentu: 1.0

Centrum Informacji jest prywatną aplikacją domową działającą na lokalnym backendzie. Ta strona nie zbiera danych odwiedzających i nie udostępnia żadnych danych kalendarza.

1. Jakie dane są pobierane z Google?

Po udzieleniu zgody aplikacja korzysta z Google Calendar API z zakresem https://www.googleapis.com/auth/calendar.readonly. Odczytuje z głównego kalendarza wydarzenia z wybranego przedziału czasu, w tym:

  • tytuł wydarzenia,
  • datę i godzinę rozpoczęcia oraz zakończenia albo informację o wydarzeniu całodniowym,
  • opis i lokalizację, jeśli są dostępne,
  • identyfikator wydarzenia oraz jego status techniczny.

Zakres odczytu jest ograniczony konfiguracją aplikacji i nie obejmuje zapisu ani modyfikacji kalendarza. Aplikacja nie prosi o dostęp do poczty, kontaktów, plików Dysku ani innych usług Google.

2. W jakim celu dane są przetwarzane?

Dane są wykorzystywane wyłącznie do odczytu wydarzeń i wyświetlenia ich w prywatnym dashboardzie Centrum Informacji. Nie są wykorzystywane do reklam, profilowania, sprzedaży, oceny użytkownika ani niezwiązanych analiz.

3. Gdzie i jak są przetwarzane?

Żądanie do Google Calendar wykonuje backend działający lokalnie na komputerze Teclast N20 Pro. Odpowiedź jest normalizowana w pamięci i zwracana klientowi aplikacji. Obecna integracja Google Calendar nie zapisuje pobranych wydarzeń do SQLite.

Poświadczenia OAuth są przechowywane lokalnie w pliku konfiguracyjnym poza repozytorium: osobno przechowywany jest plik klienta OAuth oraz plik zapisanego tokenu. Przy odświeżaniu token jest zapisywany atomowo, a nowy plik otrzymuje uprawnienia systemowe ograniczające dostęp do właściciela procesu (`0600`).

4. Zabezpieczenia i przechowywanie

Tokeny i konfiguracja OAuth są wykluczone z repozytorium. Nie są umieszczane w tej stronie, w JavaScript, w adresach URL ani w publicznych zasobach GitHub Pages. Logi aplikacji nie zawierają tokenów ani treści wydarzeń; błędy Google są rejestrowane wyłącznie jako ogólne informacje techniczne.

Bezpieczeństwo lokalnego komputera, systemu plików, konta Google i sieci domowej pozostaje odpowiedzialnością administratora instancji.

5. Usuwanie dostępu i danych

Aktualna aplikacja nie posiada osobnego panelu ani endpointu do revokacji dostępu. Aby zakończyć dostęp, administrator powinien odwołać uprawnienie „Centrum Informacji” w ustawieniach konta Google oraz usunąć lokalny plik tokenu OAuth. Plik konfiguracji klienta OAuth również można usunąć, jeśli nie jest już potrzebny.

Ponieważ wydarzenia nie są przechowywane przez tę integrację w bazie aplikacji, usunięcie tokenu usuwa lokalną możliwość kolejnego odczytu. Dane pozostające na koncie Google podlegają zasadom Google.

6. Google API Services User Data Policy

Aplikacja korzysta z danych użytkownika Google zgodnie z Google API Services User Data Policy, w tym z zasadą Limited Use:

  • używa danych wyłącznie do funkcji opisanej użytkownikowi — odczytu i prezentacji wydarzeń,
  • nie sprzedaje danych, nie używa ich do reklam ani do kredytowania,
  • nie przekazuje danych innym podmiotom poza zakresem niezbędnym do działania Google API i lokalnego backendu,
  • nie wykorzystuje danych do celów niezwiązanych z funkcją kalendarza,
  • nie używa danych kalendarza do trenowania modeli ani do generowania niezwiązanych profili.

7. Kontakt

W sprawach dotyczących tej prywatnej instancji należy skontaktować się z jej administratorem. Strona jest dokumentem informacyjnym dla użytkowników zgody OAuth; nie prowadzi formularza kontaktowego ani nie gromadzi zgłoszeń.
